    A family tree starts with one person, and the easiest one to start with is you. Everyone else gets added relative to somebody already here — your father, her mother, their children.

    Add people from a file

    A GEDCOM from Ancestry, MyHeritage, FamilySearch, Gramps or Family Tree Maker — or a spreadsheet a relative sent you. Nothing is thrown away: anything with no place to go is kept in that person's notes.

    They are added to the family file you have open. If it is not what you wanted, press Ctrl-Z once — the whole import is a single step.

    Print

    These open in a new tab with a Print button. They cover the same people the chart does, so a narrowed chart gives a narrowed dossier.
